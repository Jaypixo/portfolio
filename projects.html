Shipped · Platform

MyJay.net

An indie web hosting platform on Cloudflare's stack — Workers, D1, R2, KV, Pages. Free subdomain hosting, a blogging system, and an explore/search page that indexes Neocities and Nekoweb (respecting robots.txt). Built as a real alternative, not a demo.

Shipped · Tooling

Remarker.js

A markdown renderer built from scratch as a drop-in marked.js replacement, with extended syntax: callouts, colored spans, spoilers, keyboard shortcuts, video embeds. It's what renders this site's content and everything else I write.

In progress

MyJay Browser

A Firefox fork concept: the URL bar split into individually editable, clickable segments instead of one long string, plus a broader customization system. Specced out, not yet shipped.

In progress

Syntonist

A personal AI harness project — a from-scratch alternative to commercial chat interfaces, with its own memory system and a skills/custom-instructions layer. Ongoing.

Tooling

jpkg

JaypixOS's package manager — a friendlier CLI over pacman and the AUR. Search, install, rollback, and orphan cleanup, in commands that read like what they do. Part of the JaypixOS project, useful on its own.
