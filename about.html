About

Hi. I'm Jaypix.

I'm based in Germany, and I think about things too much — which mostly comes out as software, some of it useful, and writing, most of it written out of spite.

The technical version: I build primarily on Cloudflare's stack — Workers, D1, R2, KV, Pages — because it lets one person run infrastructure that used to need a team. I run my own hosting, my own package repo, my own markdown parser. If a tool exists and annoys me, there's a reasonable chance I've already started rewriting it.

What I actually do

Mostly indie web stuff: platforms, tools, the occasional operating system. I'd rather build the smaller, weirder version of something myself than configure the big corporate version of it. That's less a philosophy and more just how I end up spending weekends.

  • Linux — daily driver, and now the thing I ship (see: JaypixOS)
  • Cinema — I log what I watch obsessively; the count is well past a thousand
  • Writing — essays, short fiction, a diary I don't curate
  • Markdown — unreasonably, sincerely invested in it

Design, if you're wondering

Warm paper tones, IBM Plex Mono, Crimson Pro, a torn edge at the top of every page — that's the running visual thread across everything I build, this site included. Dark mode is the default; there's a toggle in the nav if you disagree.
