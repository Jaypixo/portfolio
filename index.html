JaypixOS

The biggest thing I've shipped: a KDE Plasma desktop on Arch, with its own installer, its own package manager, and its own Cloudflare-backed package repo. Not a distro fork for the sake of having one — every piece exists because the stock version of it annoyed me enough to replace.

root@jaypixos ~ # jinstall --fast
# pick a disk, pick a password, done
Starting install — Btrfs, KDE Plasma, Cloudflare DNS + NTP.
